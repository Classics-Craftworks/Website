# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com).

## v1.0.0 — 2026-11-13

### Added
- Filters & search for the changelog page
- "Join the server" card on the home page

### Changed
- Optimised seasonal themes

## v0.3.1 — 2026-11-13

No user-facing changes.

## v0.3.0 — 2026-11-13

### Added
- Changelog page with every version of the site, so you no longer need to go to GitHub to read it
  - Open it by clicking the version number in the footer
  - Each version has its own link, e.g. `/changelog#v0.3.0`
- "Mark all notifications as read" button in the Settings dropdown
- Downward chevrons to the News page's "Show more" button

### Changed
- The footer's version number now opens the Changelog page instead of GitHub
- The About page now takes up the full width, rather than wrapping halfway through
- Updated site images and logos

## v0.2.1 — 2026-11-13

### Changed
- The site now loads less code, as it no longer includes the parts of the Classic’s Craftworks site it doesn't use
- Active seasonal theme animations now pause when previewing other themes
- Improved the Aurora theme
- Updated the nav bar button order

### Fixed
- Fixed the Settings icon not being aligned to the right side of the nav bar

## v0.2.0 — 2026-11-12

### Added
- Home page: "What to expect" feature cards
- Home page: "How to join" steps with an Apply button, server addresses (with copy buttons) and a Discord ticket option
- Home page: "Supported versions" for Java and Bedrock, with the recommended versions highlighted
- Wiki & rules links in the navigation bar (open in a new tab)
- Social links in the footer

### Changed
- The site no longer uses the project system from Classic's Craftworks
- Updated news page with entries going back to the Survival Season 2 launch

### Fixed
- Fixed colour theme previews in Settings not using CraftHorizon's purple colours
- Fixed the April Fools theme description mentioning "Classic's Mudworks"

## v0.1.0 — 2026-11-12

### Added
- First version of CraftHorizon site, built from the Classic's Craftworks site
